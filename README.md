## Instructions pour executer le code

Le depot contient deux implementations pour le Lab 1 : une version Elixir et une version Java. Les scripts `bin/` sont prevus pour etre lances depuis le dossier du projet correspondant, dans un terminal bash compatible avec les scripts shell.

### Version Elixir

```bash
cd Lab1/newmath_ex
./bin/run
```

Pour executer les tests :

```bash
cd Lab1/newmath_ex
./bin/test
```

### Version Java

```bash
cd Lab1/newmath_java
./bin/compile
./bin/run
```

Pour executer les tests :

```bash
cd Lab1/newmath_java
./bin/test
```
